# SKATE — prototyp

Top-down, monochromatyczna gra na deskorolce sterowana jednym palcem (Three.js).

**Graj:** https://toniefer.github.io/skate/

- `index.html` — gra (modele wbudowane jako base64, działa też offline z pliku)
- `src/game.template.html` — kod gry z placeholderami `__GLB__` / `__BOARD__`
- `assets/toni.glb` — postać Toni (Mixamo, 7 klipów: push, idle, crouch, jump, balance, fallBal, fall)
- `assets/board.glb` — deskorolka (uproszczona do ~17k trójkątów)
